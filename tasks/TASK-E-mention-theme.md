## 背景
C++20 WebSocket 聊天室已有：全局聊天、表情、群组、AI助手、语音、管理后台、私聊DM、在线用户列表、历史消息（这些是并行任务，可能同时进行，注意协调——你只负责本任务列出的功能，**不要**修改 DM/群组/历史 相关逻辑）。

## 你要实现的功能

### 1. @提及提醒
**服务端（src/server.cpp，最小改动）：**
- 在 `type == "chat"` 分支里，解析消息文本中的 `@昵称`（正则或简单字符串匹配 `@` 后跟在线昵称）。
- 若命中某在线用户（遍历 `state.connections` 的 key），给**该用户**额外定向发送 `{"type":"mention","from":发送者,"text":整条消息,"ts":...}`；同时广播原文给所有人（现有逻辑不变）。
- 限定：只有 `@` 后跟**完整在线昵称**且以空格/行尾结束才算命中（避免误判 `@机器人` 等已占用前缀——`@机器人` 走 AI 逻辑，不冲突）。
- 不做持久化。

**前端（app.js）：**
- 收到 `{"type":"mention",...}` 时：
  - 播放一个轻提示音（用 `new Audio()` + 内置 beep 或 WebAudio 振荡器，无需音频文件）。
  - 若当前不在全局频道或页面未聚焦，标题栏闪烁显示「🔔 @你」提示。
  - 在消息列表里把该消息高亮（加 `.mention-highlight` 类，轻微抖动/背景色）。

### 2. 暗黑主题切换
**前端（style.css + app.js + index.html）：**
- 新增主题切换按钮（放 header 右上角，🌙/☀️ 图标切换）。
- 完整深色配色方案（CSS 变量方式重构：把现有颜色抽成 `--bg-*`、`--text-*`、`--accent-*` 等 CSS 变量，亮色为默认，`.dark` class 作用于 `<html>` 或 `<body>` 时切换暗色值）。
- 记住用户选择：存 `localStorage.theme`，刷新后保持。
- 默认跟随系统 `prefers-color-scheme`（无 localStorage 时）。

### 3. 前端体验增强
- 消息时间戳显示合理格式化（`HH:MM`，今天；`MM-DD HH:MM`，更早）。
- 消息气泡：自己发的靠右 + 主题色背景；别人的靠左 + 浅灰背景（当前可能已实现，确认并统一）。
- 平滑滚动：新消息到达时若在底部则自动滚动到底，用户上翻时不强制。
- 发送按钮禁用态：输入为空时禁用，输入时启用。

## 重要约束
